# Recordatorios — Actividad 1 (Programación Mobile)

App Android (Kotlin + Jetpack Compose + Material 3) que modela recordatorios con data classes
y sealed classes, valida datos simulados y los muestra en una lista filtrable.

## Cómo abrirlo
1. Android Studio → **File › Open** → seleccionar esta carpeta `Recordatorios`.
2. Aceptar la sincronización de Gradle (descarga Gradle 8.9 la primera vez).
3. Si falta la plataforma, instalar **Android 15 (API 35)** desde *SDK Manager*.
4. Crear un emulador en *Device Manager* y presionar **Run ▶**.
